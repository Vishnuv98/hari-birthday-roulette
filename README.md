# Birthday Experience

A custom interactive birthday webpage created as a personal digital surprise.

The experience includes multiple themed sections, interactive moments, animations, music, travel memories, birthday wishes, and a final “One last thing…” candle scene where the birthday wish is made.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Web Audio API
- CSS animations and transitions

## How to use

Open `index.html` in a modern web browser.

For the best experience, use a phone or desktop browser with sound enabled and interact with each section as prompted.

## Files

- `index.html` — Complete birthday website and all interactive effects.

## Notes

This project is designed as a personal birthday experience and is best viewed in full screen.
